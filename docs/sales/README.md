# docs/sales — 営業用資料

CampaignPilotの営業説明にすぐ使える文書をまとめたフォルダです。

## このフォルダのファイル

- [campaignpilot_sales_short.md](./campaignpilot_sales_short.md) — 営業用ショート文章（標準版・一言版）
- [campaignpilot_plan_list.md](./campaignpilot_plan_list.md) — プラン一覧（料金・クレジット・単価）

## 用途別の使い分け

| 場面 | 参照先 |
|---|---|
| すぐ転送・提案文に使う短い説明が欲しい | [campaignpilot_sales_short.md](./campaignpilot_sales_short.md) |
| 料金・プランを説明したい | [campaignpilot_plan_list.md](./campaignpilot_plan_list.md) |
| もう少し長い説明資料が欲しい | [../campaignpilot_sales_doc.md](../campaignpilot_sales_doc.md) |
| 商談・トークスクリプトが欲しい | [../campaignpilot_sales_talk_advanced.md](../campaignpilot_sales_talk_advanced.md)、[../campaignpilot_talk_script.md](../campaignpilot_talk_script.md) |
| 料金・クレジット設計の背景を知りたい | [../campaignpilot_credit_billing_design.md](../campaignpilot_credit_billing_design.md) |

## 価格・クレジットの確定値について

このフォルダ内の価格・クレジット数は、`scripts/seed_data/pricing_plans.json`（実際に
本番へ投入されているマスタデータ）と一致させています。価格・プランを変更する場合は、
必ず両方を更新してください（詳細な運用手順: [../MONITOR_ACCOUNT_MANAGEMENT.md](../MONITOR_ACCOUNT_MANAGEMENT.md)）。
